Alliance Tower Defense Value Calculator - starter version

Files:
- index.html = website
- style.css = design
- data.js = official values you supplied
- script.js = calculator logic

How to use:
1. Keep all 4 files in the same folder.
2. Double-click index.html to test it in your browser.
3. Left-click a unit to add it to Your Offer.
4. Right-click a unit to add it to Their Offer.
5. Change values in data.js when the official Discord list changes.

The unit images currently use the Discord CDN links you supplied.
